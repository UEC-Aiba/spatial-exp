# 空間知覚の実験アプリ（時間差と強度差）

ヘッドホンで、左右の耳に届く音の時間差（ITD）と強度差（IID）を変え、頭の中の音の位置（頭内定位）が動くかを確かめる、スマホ用の静的Webアプリです（`index.html` 1枚のみ、外部ライブラリなし）。

## 公開URL
https://uec-aiba.github.io/spatial-exp/

## 機能
- 準備：左右のチェック（左→右の順に鳴る）、音量あわせ（両耳に同じノイズ）
- さわってみる：音の種類（500 Hz 純音／4000 Hz 純音／4000 Hz 純音〔振幅変調〕／広帯域ノイズ）を選び、時間差（±800 μs）と強度差（±20 dB）をスライダーで動かして、位置の変化を聴く。左右の耳に届く波形（約 6 ms）も表示される
- 測ってみる：時間差（±600／±300／0 μs）または強度差（±12／±6／0 dB）の5段階を、ランダムな順に聴き、「頭の中のどこに聞こえたか」をスライダーで答える（各条件2回）
- 結果画面：最初に「〇〇は、時間差を変えると、位置が大きく動いた／ほとんど動かなかった」というまとめを表示し、そのあと、手がかりと聞こえた位置のグラフを表示
- 結果をCSV形式でコピーできる（授業での集計用）

## 授業用のURL設定
公開URLの末尾に次を付けると、測定モードが設定済みの状態で開く。
- `?mode=itd`：時間差で測る（500 Hz・4000 Hz の純音。20回・約 5 分）。末尾に `&reps=1` を付けると、各条件を1回ずつにして、回数を半分にする（`?mode=itd&reps=1`：10回・約 3 分）
- `?mode=iid`：強度差で測る（同上）
- `?mode=duplex`：時間差と強度差の両方で測る（40回・約 10 分；`&reps=1` で20回・約 5 分）

## 使用上の注意
- 必ずイヤホン（ヘッドホン）で使う。スピーカーでは左右の音が混ざり、結果が正しく出ない
- 音量は小さめにして、途中で変えない
- 左右の波形は、JavaScriptで計算した2チャンネル（ステレオ）の音として直接再生する。時間差は、遅れる側の信号の時間をずらして計算するので、誤差は小さい（サンプリング周期未満）
- 強度差は、左右に逆向きに半分ずつ（右 +IID/2、左 −IID/2）かけるので、全体の大きさはほぼ変わらない
- iPhone はマナーモードを解除し、Safari で開く

## 左右が逆に聞こえるとき
- アプリは、①「左右のチェック」で、左の耳に1回目、右の耳に2回目の音を出します（時間差も、強度差も、「正の値＝右の耳が先／右の耳が大きい」で作っています。JavaScriptの出力を、直接、確認済み）。
- それでも「右→左の順に聞こえる」場合は、再生する側の問題が、ほとんどです（イヤホンの左右が逆、端末の左右バランスの設定、Bluetoothイヤホンの装着の向き、など）。
- 準備の欄の、チェックボックス「右→左の順に聞こえたら、ここをオン（左右を入れ替える）」を、オンにすると、左右の出力を、入れ替えます。設定は、その端末のブラウザに、保存されます。
